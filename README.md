# ASHEN VIGIL: THE LAST BELL / 灰の番人 ― 最後の鐘

Godot 4.7.2 / GDScript製の短編2D高難度アクションです。滅びた鐘楼へ向かう「灰の巡礼者」となり、死を記憶に変えながら鐘守ヴァルグリムを倒してください。想定クリア時間は10～15分です。

## 起動方法

最短手順は `PLAY_GAME.bat` をダブルクリックするだけです。検証済みのGodot 4.7.2本体を `.tools/godot-4.7.2/` に同梱しています。

1. Godot 4.7.2でこのフォルダの `project.godot` を開きます。
2. F6ではなくF5（プロジェクト実行）を押します。メインシーンは設定済みです。

同梱の検証用エンジンが存在する場合は、PowerShellから次でも起動できます。

```powershell
& '.\.tools\godot-4.7.2\Godot_v4.7.2-stable_win64.exe' --path .
```

## 攻略の要点

- 深紅または橙色の発光は攻撃・罠の予兆です。
- 通常攻撃は3段までつながり、最終段が強力ですが硬直も長くなります。
- 回避には無敵時間がありますが、スタミナを30消費します。
- 回復は大きく回復する代わりに地上で約0.7秒無防備になります。
- 青白い霊火がチェックポイントです。HP・スタミナ・霊薬3個を補充します。
- ボス前の霊火から再挑戦できるため、復帰は短時間です。

## 実装内容

- 加減速、可変ジャンプ、コヨーテタイム、先行入力
- 3段コンボ、回避無敵、スタミナ、回復、ノックバック、被弾無敵
- 分離されたHitbox/Hurtboxと1攻撃1ヒット制御
- 近接「灰の衛兵」、遠距離「呪鐘師」、待ち伏せ突進「墓影」のステートマシンAI
- 4攻撃・第二相専用攻撃を持つボス「鐘守ヴァルグリム」
- 固定トゲ、周期トゲ、接近反応落槍、落下死、足場戦闘
- タイトル、操作説明、設定、HUD、ポーズ、リトライ、クリア画面
- チェックポイント、死亡回数、JSONセーブ、破損時フォールバック
- 生成タイトルアート、コード描画キャラクター、パララックス背景、画面揺れ、ヒットストップ、各種エフェクト
- ランタイム生成のオリジナルBGM・効果音（外部音源不使用）

## ファイル構成

- `scenes/` — メイン、ステージ、プレイヤー、敵、ボス、罠、飛び道具、チェックポイント
- `scripts/` — ゲームロジック、AI、UI、セーブ、音響、演出、背景
- `resources/` — Inspector調整可能なプレイヤーバランスResource
- `assets/title_background.png` — OpenAI ImageGenで本作向けに生成したタイトル背景
- `project.godot` — 入力、表示、Autoload、メインシーン設定

## Godotエディタで編集する

- `scenes/main.tscn` — 実ノード化されたタイトル画面を含むメインシーン
- `scenes/title_screen.tscn` — 背景、パネル、ラベル、各ボタンを2D/UIエディタで編集
- `scenes/level.tscn` — ステージ全体。`Stage/Platforms`、`Stage/Hazards`、`Actors`、`Checkpoints`から配置を直接編集
- `scenes/platform.tscn` — 足場の共通シーン。各インスタンスの`size`と色をInspectorで変更
- `scenes/player.tscn`、`enemy.tscn`、`hazard.tscn`、`checkpoint.tscn`、`boss.tscn` — 再利用可能なゲーム要素

プレイヤー、敵、罠、チェックポイント、ボスは`@tool`プレビュー対応です。`level.tscn`を2Dエディタで開くと実際の配置と外観が表示され、移動・複製・削除、敵種別、罠種別、サイズ、ダメージ、周期などをInspectorから変更できます。実行時に必要な一時オブジェクト（攻撃判定、飛び道具、エフェクト、リスポーン個体）のみスクリプトで生成されます。

詳しい編集箇所は `EDITOR_EDITING.md` を参照してください。

## 素材とライセンス

外部アセットは使用していません。タイトル背景は本プロジェクト用にOpenAI ImageGenで生成し、それ以外の映像素材・アイコン・アニメーションはGDScriptの描画APIで生成しています。音響も実行時に波形を合成します。
